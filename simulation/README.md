# Simulation

This folder is reserved for simulation and testing resources for the Mine Vehicle Safety System.

## Planned Testing Scenarios

- Normal visibility
- Fog and low visibility
- Static obstacles
- Moving mine vehicles
- Personnel detection
- Different vehicle speeds
- Different detection distances
- Warning-level transitions

## Testing Pipeline

```text
Test Scenario
      ↓
Camera / Sensor Input
      ↓
AI Detection
      ↓
Visibility Analysis
      ↓
Risk Analysis
      ↓
Warning Level
      ↓
System Response
