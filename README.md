# Mine Vehicle Safety System

## SIH 2026 — Technical Approach

**Problem Statement:**  
**Safe and Efficient Operation of Mine Vehicles in Fog and Low-Visibility Conditions in Open Cast Iron Ore Mines**

## Overview

This project proposes a real-time safety-assistance system for open-cast iron-ore mine vehicles operating in fog and other low-visibility conditions.

The system combines camera-based perception, suitable distance/environment sensors, AI-assisted detection, risk analysis and operator alerts to improve situational awareness.
